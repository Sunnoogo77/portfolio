# Icones de technologies

Les fichiers `.svg` de ce dossier proviennent de **Simple Icons**, publies sous
**CC0 1.0 Universal**, c'est-a-dire verses au domaine public.
Source : <https://simpleicons.org/>.

Ils sont recuperes tels quels, sans modification.

Les marques qu'ils representent restent la propriete de leurs detenteurs
respectifs. Elles sont employees ici de maniere purement descriptive, pour
indiquer les technologies mises en oeuvre dans un projet, et non pour suggerer
une affiliation, un partenariat ou une approbation quelconque.

`wazuh.png` ne figure pas dans Simple Icons. Il provient du dossier de logos du
CV, ou il etait deja utilise dans le meme but descriptif.

Toute technologie sans icone s'affiche en texte seul : le rendu ne doit jamais
dependre de la presence d'un fichier ici.
