# Polices embarquees

Les quatre fichiers `.woff2` de ce dossier sont les sous-ensembles latin et
latin-ext publies par Google Fonts, recuperes tels quels depuis
`fonts.gstatic.com`. Aucune modification n'y a ete apportee. Ce sont les
fichiers variables : un seul fichier par sous-ensemble couvre toute la plage de
graisses, ce qui evite de telecharger deux fois les memes octets et empeche le
navigateur de fabriquer un faux gras.
